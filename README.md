# 📘 Guía Rápida: Tamaños de Fuente en Tailwind CSS

Tailwind CSS ofrece una forma sencilla y flexible de controlar los tamaños de fuente usando clases utilitarias.

## 🎯 Tamaños de fuente predeterminados

Los tamaños de fuente en Tailwind van generalmente en incrementos de 2 píxeles. A continuación se muestra una tabla con los valores comunes:

| Clase      | Tamaño (px) | Descripción       |
|------------|-------------|-------------------|
| `text-xs`  | 12px        | Extra chica       |
| `text-sm`  | 14px        | Chica             |
| `text-base`| 16px        | Mediana (por defecto) |
| `text-lg`  | 18px        | Grande            |
| `text-xl`  | 20px        | Extra grande      |
| `text-2xl` | 24px        | 2 veces extra     |
| `text-3xl` | 30px        | 3 veces extra     |
| `text-4xl` | 36px        | 4 veces extra     |
| `text-5xl` | 48px        | 5 veces extra     |
| `text-6xl` | 60px        | 6 veces extra     |
| `text-7xl` | 72px        | 7 veces extra     |
| `text-8xl` | 96px        | 8 veces extra     |
| `text-9xl` | 128px       | 9 veces extra     |

## ✨ Line Height (`leading`)

| Clase           | Valor aproximado | Descripción           |
|-----------------|------------------|------------------------|
| `leading-none`  | 1                | Sin espacio entre líneas |
| `leading-tight` | 1.25             | Espaciado muy corto    |
| `leading-snug`  | 1.375            | Espaciado compacto     |
| `leading-normal`| 1.5              | Valor por defecto      |
| `leading-relaxed`| 1.625           | Espaciado relajado     |
| `leading-loose` | 2                | Espaciado amplio       |

## 🧭 Text Align (`text-align`)

| Clase           | Alineación       |
|-----------------|------------------|
| `text-left`     | Izquierda (default) |
| `text-center`   | Centrado         |
| `text-right`    | Derecha          |
| `text-justify`  | Justificado      |
| `text-start`    | Según el idioma (LTR/RTL) |
| `text-end`      | Opuesto a `start` |

---

## 🧷 Align Items (`align-items` en Flex/Grid)

| Clase             | Alineación vertical        |
|------------------|-----------------------------|
| `items-start`    | Alineados arriba            |
| `items-center`   | Centrado verticalmente      |
| `items-end`      | Alineados abajo             |
| `items-stretch`  | Estirados (default en grid) |
| `items-baseline` | Según línea base del texto  |
